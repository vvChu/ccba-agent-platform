# ccba-harness Package Guidance

Deterministic evaluation framework for benchmarking AI Agent skills and workflows.

- **Public Deep Seams**: `from ccba_harness import HarnessEngine, HarnessGuard, FileMutexLock, HarnessLocal, HarnessState, DetachedExecutionEngine, EvalRunner, EvalItem, EvalReport, ExactMatchScorer, RegexScorer, JsonSchemaScorer, LengthBoundsScorer, LLMRubricScorer, SkillValidator, SkillAuditIssue, ArchitectureTier, GPIMetrics, DecisionRequest, DecisionResult, calculate_gpi, evaluate_two_stage_decision, GPI_STANDALONE_THRESHOLD, GateCheck, GateResult, check_ast_function_length, check_module_size_budget, check_redundant_comments, run_full_gate, run_implementation_gate, BlastRadiusReport, analyze_blast_radius, ADRMatch, WhyExplanation, explain_architecture_why, apply_anchor_patch, extract_anchor_payload, AutoApplyResult, auto_apply_and_verify_patch, run_apply_anchor_patch_cli, run_peer_dispatch_cli, orchestrate_peer_co_review, synthesize_verdicts, PeerConsensusReport, run_peer_co_review_cli`.
- **CLI Commands**: `ccba-harness validate-skill [paths...] [--file FILE] [--root ROOT] [--strict] [--enforce-gpi]`, `ccba-harness evaluate-gpi [--file FILE] [--name NAME] [--s S] [--k K] [--a A] [--p P] [--deterministic] [--orchestrated] [--parent PARENT] [--json]`, `ccba-harness peer-gate [--branch BRANCH] [--file FILE] [--output-verdict] [--json]`, `ccba-harness peer-watch [--dir DIR] [--root ROOT] [--once] [--watch] [--interval N] [--auto-gate] [--auto-grok]`, `ccba-harness peer-dispatch --prompt-file FILE [--profile PROFILE] [--tier TIER] [--model MODEL] [--max-turns N] [--timeout SEC] [--worktree] [--dry-run] [--auto-apply] [--verify-preset PRESET] [--keep-backups] [--root ROOT]`, `ccba-harness peer-co-review --prompt-file FILE [--profiles PROFILES...] [--output-file FILE] [--max-workers N] [--timeout SEC] [--worktree] [--dry-run] [--json] [--auto-apply] [--patch-file FILE] [--verify-preset PRESET] [--keep-backups] [--root ROOT]`, `ccba-harness apply-anchor-patch --patch-file FILE [--root ROOT] [--dry-run] [--backup] [--quiet] [--json]`, `ccba-harness blast-radius [targets...] [--root ROOT] [--json]`, and `ccba-harness why <query> [--root ROOT] [--json]`.
- **Contracts**: Evaluations must be deterministic and isolated with explicit timeout guards. Two-Stage Granularity Decision Framework and GPI calculation enforce RES-2026-ARCH-001 v1.2 architecture rules. Fast unit tests must maintain SLA < 2.0s.
- **Scoped Tests**: `pytest packages/ccba-harness/tests`
