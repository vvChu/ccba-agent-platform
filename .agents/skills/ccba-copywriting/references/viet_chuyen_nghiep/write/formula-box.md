# Công Thức Hộp — Formula Box

**Module:** write/formula-box
**Mục đích:** Format công thức/mô hình quan trọng trong tài liệu kỹ thuật hoặc sách giáo khoa.

---

## Format chuẩn

```markdown
| 💡 **Công thức [Tên]:** |
| :--- |
| [Thành phần A] + [Thành phần B] = [Kết quả] |
```

## Quy tắc

- Tối đa 1 công thức hộp mỗi section H2
- Tiếng Việt trước, (*English*) italic theo sau trong ngoặc
- Ký hiệu: `+` (kết hợp), `×` (nhân), `→` (tuần tự), `↻` (vòng lặp)

## Ví dụ

```
| 💡 **Công thức KWSR:** |
| :--- |
| Kiến thức (*Knowledge*) → Quy trình (*Workflow*) → Kỹ năng (*Skill*) → Quy tắc (*Rule*) |
```

```
| 💡 **Công thức IPO:** |
| :--- |
| Đầu vào (*Input*) + Xử lý (*Process*) + Đầu ra (*Output*) = Yêu cầu hoàn chỉnh |
```
