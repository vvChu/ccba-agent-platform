# 6. Quality and Context Optimization for Academic Writing Skill

We decided to align the `academic_writing` skill with the `writing-great-skills` quality constitution. This involves defining explicit, verifiable completion criteria for each phase in the execution logic, extracting the mock audit report format to an external reference file (`references/audit_report_format.md`) to follow the progressive disclosure principle, and configuring the skill as user-invoked by setting `disable-model-invocation: true` to optimize the context window footprint.
