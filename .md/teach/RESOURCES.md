# Danh Mục Tài Nguyên: AI-Assisted Coding

## Nguyên lý Cốt lõi
- **Orchestration > Memorization:** Trong kỷ nguyên AI, năng lực thiết kế kiến trúc và mô tả bài toán quan trọng hơn việc nhớ cú pháp dấu chấm phẩy.
- **Specification-Driven Development (SDD):** Viết đặc tả rõ ràng trước khi code.
- **Feedback Loops & TDD:** Cho AI biết thế nào là "Đúng" bằng các phép thử (Tests/Checks).

## Công cụ Thực hành
- **AI Coding Assistants:** Antigravity Agent, Claude Code, GitHub Copilot, Cursor.
- **Môi trường chạy:** Trình duyệt web (HTML/JS) hoặc Python Scripts.
